# PEX 钱包交易接入（2026-09-28）

网页使用 SDK 0.3.0，插件使用 0.7.0。下单传递 chainId、买卖方向、类型、原始数量、价格边界和最大手续费；网站不能指定收款方、查看密钥、proof 或 calldata。所有资金操作在插件内确认。

- 下单：插件先生成证明/官网加密预检，再请求最终资金确认。
- 未确认：页面显示恢复记录与继续检查，不把返回超时当作失败重下。
- 撤单：检查在途成交，取消订单，再恢复剩余本金与未使用手续费；链上确认前不会显示资金已回收。
- 成交：Sync fills & assets 在插件中验证收款并同步隐私资产。订单状态查询仍来自官方 Matcher。
- 旧插件：显示升级提示，余额授权不会被误当成交易能力。

插件持久化恢复材料，网页只在内存中保存公开摘要。普通 Vault 导出目前不包含 PEX 恢复日志；有待恢复订单时应保留插件存储。原官网导入的旧订单仍为只读引用。Matcher 换轮次且无法确认在途成交时停止自动回收。

已验证：官网两组加密测试预检通过，真实 WASM 买入/卖出资金证明与本金/手续费回收证明通过，真实扩展两次审批和拒绝流程通过，网页 56 项桌面/手机 E2E 通过。没有使用用户钱包、提交真实订单或完成主网成交/回收验收。预编译证明产物已固定哈希，但不代表独立安全审计。

完整协议与文件边界见同级 plabs-wallet-extension/docs/PEX-TRADING.md。
