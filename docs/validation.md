## 2026-09-28 授权按钮无反馈修复

错误与进度现在直接显示在授权按钮下，并在手机 Drawer 中保持可见。每次请求重新核对扩展实际能力；旧版扩展、拒绝请求、无回应、权限不完整都有明确反馈。等待授权期间允许重新打开钱包，不再被全局请求锁吞掉。

插件 0.6.1 增加工具栏弹窗失败时的独立确认窗口，并以 runtime.getContexts 识别本扩展页面、复用窗口，无新增 tabs 权限。扩展重载造成的 content-script 同步错误现在返回断线结果。

验证：网页 76 项单元测试、54 项桌面/手机 E2E，扩展 77 项单元测试通过。真实加载 0.6.1 的独立测试 profile 中，强制令 action.openPopup 失败，实际点击网站授权与插件确认 UI，完成拒绝→重试→批准→读取余额，以及隐私锁定→解锁→批准→读取的链路；使用生成的测试 Vault 和模拟链数据，没有使用用户账户或发送交易。

修复需要在浏览器扩展管理页重新加载原 plabs-wallet-extension/dist，再刷新网页。安装包为 releases/plabs-wallet-extension-0.6.1-store.zip。
